# Platform 2 sprite library

These transparent PNGs are individual platform cutouts from the root `first_light_platforms2.png` atlas. Each file is cropped to its artwork and can be assigned directly as a `Texture2D` on a Sprite2D or Sprite3D.

| File | Sprite |
| --- | --- |
| `01_island_lantern_wide.png` | Wide floating island with lantern and railing |
| `02_portal_island.png` | Tiered island with stone portal |
| `03_suspension_bridge.png` | Wide island bridge |
| `04_ladder_island.png` | Lantern island with hanging ladder |
| `05_crate_island_bridge.png` | Crate island with wooden support |
| `06_wide_rock_ledge.png` | Wide rocky ledge with ferns |
| `07_floating_stone_small.png` | Small floating stone |
| `08_lantern_ledge_wide.png` | Wide lantern island |
| `09_fern_island_left.png` | Fern covered island with a tall left edge |
| `10_stepping_stone.png` | Small stepping stone |
| `11_fern_island_mid.png` | Fern covered floating island |
| `12_reinforced_ledge.png` | Island ledge with wooden support |
| `13_rocky_fern_ledge.png` | Rocky fern covered island |
| `14_supply_crate_island.png` | Small island with supply crates and lantern |
| `15_wood_support_ledge_tall.png` | Narrow ledge with tall wooden support |
| `16_wood_support_ledge_double.png` | Short ledge with twin supports |
